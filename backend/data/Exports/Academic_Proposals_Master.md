## 47. TriMetric: High-Granularity Metric Subpartitioning and Triangle-Inequality Pruning Engine (DSA)
- **Core Concept**: Accelerates vector nearest-neighbor search by subdividing coarse clusters and using triangle-inequality distance bounds to losslessly prune non-candidate vectors without computing high-dimensional distances.
- **Viability Score**: 93 / 100 | **Difficulty**: Advanced
- **Core Mechanism**: Hierarchical metric clustering combined with Triangle Inequality Pruning: for query q, sub-centroid c, candidate vector x, and current k-th nearest neighbor radius R, vectors are skipped without distance evaluation whenever |d(q, c) - d(x, c)| > R.
- **Paper**: Tribase: A Vector Data Query Engine for Reliable and Lossless Pruning Compression using Triangle Inequalities (2025)
